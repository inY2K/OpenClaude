Features

nothing you don't

OpenClaude is intentionally minimal. No bloat, no dependencies, just powerful provider switching.

🌐
Any Provider
Works with OpenAI, DeepSeek, Groq, SiliconFlow, Together AI, Fireworks, OpenRouter, Anthropic, or any compatible endpoint.
🏠
Local Models
Run Ollama or LM Studio on your own machine — zero API cost, fully private, no internet required.
🔄
Live Switching
Switch providers while Claude Code is running — no restart needed. Change models on the fly.
🎛️
Per-Tier Models
Assign different models to Opus / Sonnet / Haiku / Subagent tiers. Use cheap models for simple tasks, powerful ones for complex work.

No Lock-in
Switch providers any time. Your config lives on your machine. MIT licensed — fork it, hack it, build on it.

FAQ

Frequently asked questions

Do I need to pay for anything?
OpenClaude itself is completely free and open source. You only pay for the AI provider you choose — and if you use Ollama or LM Studio with local models, everything is free. Many cloud providers also offer generous free tiers (Groq, OpenRouter, etc.).
Is my API key safe?
Yes. Your API key is stored only in ~/.openclaude/config.db on your own computer. OpenClaude only sends it to the provider you configured — the same place you'd send it anyway. It's never transmitted to any third party, server, or analytics system.
Does it work with any AI provider?
Any provider that supports either the OpenAI Chat Completions format (/v1/chat/completions) or the Anthropic Messages format (/v1/messages) will work. This covers virtually every major provider and most self-hosted options.
Can I use multiple providers and switch between them?
Yes! Add as many providers as you like during setup. Switch between them with openclaude --switch <alias> — even while Claude Code is running. The switch is instant, no restart needed.
Will Claude Code know I switched providers?
No. From Claude Code's perspective, it always talks to the same local proxy. The provider switch is completely transparent. Claude Code works exactly the same regardless of which model powers it.
How do I update OpenClaude?
Run git pull from the OpenClaude folder. Your config is stored separately in ~/.openclaude/config.db and won't be affected by updates.
